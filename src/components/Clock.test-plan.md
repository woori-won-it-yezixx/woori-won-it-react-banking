# Clock 테스트 계획

대상: `src/components/Clock.jsx`

## 테스트 시나리오

| 단계        | Given                                     | When                       | Then                                         |
| ----------- | ----------------------------------------- | -------------------------- | -------------------------------------------- |
| 초기 표시   | fake timers와 고정된 현재 시각을 준비한다 | `Clock`을 렌더링한다       | `ko-KR` 시간 형식으로 고정된 시각이 표시된다 |
| 시각 갱신   | 초기 시각으로 `Clock`을 렌더링한다        | fake timers를 1초 진행한다 | 다음 시각이 표시된다                         |
| 타이머 정리 | `Clock`이 마운트된 상태를 준비한다        | 컴포넌트를 언마운트한다    | `clearInterval`이 호출된다                   |

## 실행 방법

```bash
npm test -- src/components/Clock.test.jsx
```

시간과 타이머를 Vitest fake timers로 제어해 시스템 시간이나 실제 대기 시간에 의존하지 않도록 한다.
